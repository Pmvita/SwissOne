## Locked direction

Quiet alpine precision. Brand first in the hero; no card clutter in first viewport.

### Typography

| Role | Font |
|------|------|
| Display / brand | **Cormorant Garamond** |
| Body / UI | **Source Sans 3** |

### Color tokens

| Token | Hex |
|-------|-----|
| Snow | `#F7FAFC` |
| Glacier | `#E8EEF2` |
| Ink | `#0B1220` |

| Brass | `#A67C52` |

Hero: full-bleed alpine night → snow fade; mountain silhouette; `FadeIn` / `SlideIn` only.

### Motion

1. Hero brand fade-in  
2. CTA slide-up  
3. Subtle page transitions via shared animated link button  

### Avoid

Purple gradients, cream+terracotta newspaper layouts, floating promo badges on hero media.
